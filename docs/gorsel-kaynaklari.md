# Görsel ve font kaynakları

Turla'da kullanılan, Turla ekibine ait olmayan görsel ve yazı tipleri ile lisansları.

## Yazı tipleri (uygulamaya gömülü)

| Font | Kaynak | Lisans |
|---|---|---|
| Fraunces (SemiBold, 9pt) | github.com/undercasetype/Fraunces | SIL Open Font License 1.1 (`packages/core/assets/fonts/fraunces/OFL.txt`) |
| IBM Plex Sans (Regular, Medium, SemiBold) | github.com/IBM/plex | SIL Open Font License 1.1 (`packages/core/assets/fonts/ibm_plex_sans/LICENSE.txt`) |
| IBM Plex Mono (Medium) | github.com/google/fonts | SIL Open Font License 1.1 (`packages/core/assets/fonts/ibm_plex_mono/OFL.txt`) |
